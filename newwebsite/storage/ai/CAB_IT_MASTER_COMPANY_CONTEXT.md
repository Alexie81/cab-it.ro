# 19. Căutare semantică

Pentru căutare semantică, sistemul poate folosi un model multilingual de embeddings.

Principiul:

întrebare utilizator

→ embedding query

→ comparare cu embeddings ale fragmentelor

→ similarity score

→ reranking

→ top rezultate.

Semantic search trebuie combinat cu lexical search.

---

# 20. Hybrid Search

CAB-IT AI nu trebuie să depindă exclusiv de embeddings.

Folosește un sistem hibrid:

* FTS;
* keyword matching;
* semantic similarity;
* source priority;
* intent matching.

Exemplu:

`canonical`

este un termen foarte specific.

FTS îl poate identifica excelent.

Pentru:

„Google îmi alege altă adresă decât cea pe care o vreau”

semantic search poate identifica același concept chiar dacă utilizatorul nu spune cuvântul `canonical`.
